# Fake News Detection Using BiLSTM and Attention

A deep learning NLP project that classifies news articles as Fake or Real using BiLSTM and Attention Mechanism.

## Technologies Used
- Python
- TensorFlow
- Keras
- NLP
- Streamlit
- Scikit-learn

## Run Application

```bash
streamlit run app.py
```

## Features
- NLP preprocessing
- BiLSTM model
- Attention mechanism
- Real-time prediction
- Streamlit web app
